Wokwi: a placa inteira dentro do VS Code

Mesmo circuito

O diagram.json segue o mesmo mapa de pinos da placa real

Peças trocadas

MQ-135, chuva e solo viram potenciômetros que eu giro na hora

Digital pelo Touch ID

O leitor do Mac faz o papel do AS608 para armar e desarmar

Um comando

./firmware/wokwi.sh demo

13 · firmware/diagram.json · MicroPython 1.29.0

O Wokwi simula o ESP32 com MicroPython 1.29 dentro do VS Code. O circuito tem exatamente as mesmas ligações da placa real, então o Python gerado pelo compilador roda nos dois sem mudar uma linha. Os sensores que o Wokwi não tem viram potenciômetros, e o Touch ID do Mac substitui o leitor de digital. O wokwi.sh demo compila o .aeg, envia para o simulador e abre o painel web.

A LINGUAGEM AEGIS

Uma linguagem com vocabulário de sobrevivência

scavenge gpio
law ALARM_RADIO = 5
mission check_perimeter() -> status {
    supply detected = gpio.read(radio(27))
    extract detected
}
survivor perimeter_watch {
    watch {
        checkpoint (check_perimeter()) {
            broadcast(radio(ALARM_RADIO))
        } fallback {
            log_entry("area limpa, nenhum sinal")
        }
        hide(500)
    }
}

04 · AEGIS — do compilador ao abrigo

AEGIS é uma linguagem de domínio específico. A estrutura é a de qualquer linguagem imperativa (constantes, funções, condicionais, laços), mas o vocabulário é de sobrevivência para o código se ler como o diário de operação do abrigo. São 29 palavras reservadas em 7 categorias. O exemplo da esquerda vigia o sensor de presença: se detectar alguém, liga o alarme; senão, registra que a área está limpa.

O gerador percorre a árvore e escreve Python. Repare no global risco: em Python, atribuir a uma variável de fora dentro de uma função exige o global, e o gerador percebe isso sozinho. O mesmo código sai para dois alvos com a mesma API de hardware: simulado, para testar no PC, e esp32, para MicroPython. O arquivo gerado já traz o runtime embutido e um mapa de linhas, então um erro no Python aponta a linha do .aeg.

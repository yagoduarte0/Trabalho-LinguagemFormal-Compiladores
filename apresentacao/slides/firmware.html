// firmware/abrigo.aeg

survivor sentinela_calor {
    temperatura = climate.temperature(radio(PINO_DHT))
    risco_calor = NORMAL
    checkpoint (temperatura >= TEMP_ALARME) {
        risco_calor = ALARME
    } fallback checkpoint (temperatura >= TEMP_ATENCAO) {
        risco_calor = ATENCAO
    }
}

Aqui a linguagem deixa de ser exemplo e vira produto. O firmware do abrigo tem 810 linhas de AEGIS e vira 1.262 linhas de MicroPython. Cada sensor tem um survivor, como este do calor: lê o DHT22 e classifica o risco com checkpoint e fallback checkpoint. A cada ciclo de meio segundo, os nove survivors rodam e o pior risco decide a reação.
